# บันทึกการแก้ไขหน้า Admin ไม่โหลดข้อมูลเมื่อกลับเข้าหน้าเดิม

วันที่ดำเนินการ: 15 กรกฎาคม 2026

## อาการ

- เมื่อเปิดหน้าในระบบ Admin ครั้งแรก ข้อมูลแสดงตามปกติ
- เมื่อไปหน้าอื่นแล้วกลับมาหน้าเดิม ข้อมูลอาจไม่แสดง

## สาเหตุ

หน้า Admin โหลดข้อมูลผ่าน `useEffect` ทุกครั้งที่ component ถูกสร้าง ขณะเดียวกันโปรเจกต์เปิด React `StrictMode` ซึ่งในโหมดพัฒนาสามารถเรียก effect ซ้ำได้ หน้าที่โหลดข้อมูลจากหลาย endpoint จึงอาจเกิด GET request ชุดเดียวกันพร้อมกันหลายรายการ และการกลับเข้าหน้าเดิมอาจพบ request เดิมที่ยังดำเนินการอยู่

## การแก้ไข

1. เพิ่ม `key={route}` ให้ `AdminPageContent` เพื่อให้แต่ละ route มี lifecycle ของตัวเองและสร้างสถานะหน้าใหม่เมื่อ route เปลี่ยน
2. รวม GET request ที่มี path และ token เดียวกันใน `src/api/admin.js` ให้ใช้ Promise เดียวกันระหว่างที่ request ยังทำงาน
3. ลบ request ออกจากรายการรอเมื่อสำเร็จหรือผิดพลาด เพื่อให้การกลับเข้าหน้าครั้งถัดไปโหลดข้อมูลล่าสุด
4. POST, PUT และ DELETE ยังทำงานทุกครั้งตามเดิม

## ไฟล์ที่แก้ไข

- `src/api/admin.js`
- `src/pages/admin/AdminApp.jsx`
- `ADMIN_DATA_RELOAD_FIX.md`

## ผลที่คาดหวัง

- เปิดหน้า Admin ครั้งแรกได้ตามปกติ
- ไปหน้าอื่นแล้วกลับมาหน้าเดิม ระบบโหลดและแสดงข้อมูลอีกครั้ง
- ลด GET request ซ้ำที่เกิดจาก React `StrictMode`
